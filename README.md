# 🟡 Pac-Man: Verschiebbare Gänge

Ein moderner Pac-Man-Klon mit **verschiebbaren Gängen** — im Neumorphismus-Design.

## Features

- **Verschiebbare Gänge:** Schalte den Shift-Modus an und swip horizontal über eine Reihe, um den ganzen Gang zu verschieben
- **4 Geister mit individueller KI:** Blinky (verfolgt), Pinky (überlistet), Inky ( flankiert), Clyde (zufällig)
- **Power Pills:** Iss sie, um Geister zu essen
- **Neumorphismus-Design:** Weiche Schatten, runde Formen, modernes UI
- **Mobile-freundlich:** Touch D-Pad + Swipe-Steuerung
- **Reines HTML/CSS/JS:** Keine Dependencies, läuft überall

## Steuerung

| Aktion | Desktop | Mobile |
|---|---|---|
| Bewegen | Pfeiltasten / WASD | D-Pad Buttons |
| Gang verschieben | — | Swipe horizontal auf Reihe (Shift-Modus an) |
| Shift-Modus | — | Toggle-Switch |
